# Production launch checklist / قائمة الإطلاق

- [x] Bilingual website files generated (Arabic/English).
- [x] Static HTML pages and all local references audited.
- [x] JavaScript parsed by Node.js.
- [ ] Deploy to a public accessible URL.
- [ ] Execute end-to-end browser tests using sample PDFs / images for each tool; validate downloads and output structure.
- [ ] Configure Search Console and request indexing.
- [ ] Confirm eligible AdSense website address and account ownership.
- [ ] Add verified publisher's ads.txt record and AdSense code *only after confirming correct account*.
- [ ] Privacy/cookie consent implementation if required based on actual ad deployment and target regions.
- [ ] Submit site for official AdSense review.

No approval guarantee; AdSense review is a separate Google decision. Do not claim launch-ready until all applicable items are verified.

When to use this tool

Rotate PDF helps correct scanned pages that are sideways or upside down while other pages are already upright. It changes selected pages' rotation without converting the PDF pages into images.

How to use it

Select a PDF and choose a rotation angle. Enter a range such as 1,4-6 to rotate only those pages, or leave the page selector blank to rotate all pages. Process the file and download rotated.pdf.

Limits and cautions

The selected rotation is added to each page's existing angle, so a 90-degree selection does not guarantee that all pages will appear in portrait mode. Some PDF viewers handle rotation metadata differently.

Check before sharing

Open the new document and inspect both selected and unselected pages to ensure only the intended orientation changed. If the sequence also needs correction, use Organize Pages as a separate step.

🔒 Your files stay private

Files are processed on your device with JavaScript and are not uploaded to our servers. An internet connection is needed to load certain libraries.

PDF under 2 MB: check file size before uploading

Check a PDF against a 2 MB or 5 MB upload limit locally and learn when compressing a document can reduce readability.

Some job, scholarship and university portals set an upload limit of 2 MB or 5 MB per PDF. Before compressing a document, check whether it already fits. Changing a readable original unnecessarily can sometimes make it worse.

Check your PDF size without uploading

Enter the limit set by your application portal. Only file size metadata is checked.

Select a PDF to check its size.

We use 1 MB = 1,000,000 bytes; MiB uses a different unit.

Five steps to meet a PDF upload limit

  1. Check whether the portal's size limit applies to each attachment or to the complete submission.
  2. Measure your file using the local size checker above.
  3. If a scanned document is too large, try Compress PDF, saving the result as a separate file.
  4. Open the output and inspect small print, stamps, numbers and signatures.
  5. Check the final file size again. Never upload an unreadable result just because it fits.

Important compression limitations

PixPDFKit's PDF compressor renders pages as images in a new PDF. That may reduce some image-heavy scans, but searchable or selectable text can be lost, small text may look fuzzy, and the output can occasionally be larger. If your original CV is text-based, consider exporting a smaller file from the source editor instead.

Converting photos to a PDF

Rotate and crop source photos before using Images to PDF. Combine separate PDFs using Merge PDF if needed, then verify the size of the complete file.

Frequently asked questions

Is 2 MB equal to 2 MiB?

No. 2 MB is 2,000,000 bytes; 2 MiB is 2,097,152 bytes. Follow the portal's definition and leave a little margin.

Does this checker upload my document?

No. It compares file metadata reported by your browser without reading or sending the PDF contents.

Can every PDF be reduced below 2 MB?

No. Results depend on the original document. Readability and accuracy are more important than achieving an arbitrary size.

Combine CV and certificates into one PDF for a job application

Organize your resume, certificates and supporting documents into a single readable PDF, with file size and privacy checks.

Before merging your CV and certificates, check the employer's instructions. Some hiring portals request one combined PDF; others require separate documents in different upload fields.

Suggested order if one PDF is required

  1. Resume or CV first: let the reviewer see your profile immediately.
  2. Cover letter: include it if requested or relevant.
  3. Qualifications and certificates: place the most relevant documents first.
  4. Experience and training: attach only useful, requested evidence.

There is no universal required order. Follow the employer's rules when specified.

How to prepare the document

Use Images to PDF if a certificate is a clear photo. Open Merge PDF, add the PDFs in the intended order and review the file list. Download the result and open it again before submitting.

Final checklist

  • All pages are present, legible and correctly oriented.
  • The PDF has a clear filename such as CV_Certificates.pdf, without unnecessary sensitive identifiers.
  • No extra personal documents are included unless explicitly requested.
  • Check the file limit with the PDF size checker.
  • Avoid modifying digitally signed documents when the signature must remain valid: merging may invalidate it.

What if separate uploads are required?

Do not merge. Use Split PDF only when you need a particular range of pages, and review each output before uploading it.

Privacy

PixPDFKit's PDF tools process files in your browser rather than on a document-processing server. Still, downloaded copies remain on your device and should be handled carefully.

# OFUQ TV — GitHub Pages (2026-10-29)

This subdirectory is a freely-hosted prototype of the OFUQ TV digital channel. Its newsroom preview is deliberately **not represented as a real live broadcast**.

Public viewer: https://mazooniosman299-blip.github.io/ofuq-tv/
Studio preview: https://mazooniosman299-blip.github.io/ofuq-tv/broadcast.html

To embed a verified public YouTube Live broadcast, update the public video id in `config.js`: `youtubeVideoId`. Do NOT commit YouTube stream keys. Keep OBS keys private.

GitHub Pages is static: it does not encode or transmit a live video stream. Actual live output requires OBS on a computer, a YouTube channel with live streaming enabled, suitable original programming and a stable connection.

Original visual identity. No copyrighted third-party clips or channel branding.

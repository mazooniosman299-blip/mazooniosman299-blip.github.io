# أُفُق TV — الموقع العام

تم حذف جميع البرامج والمشاهد والفيديوهات التجريبية من النسخة العامة. لا يعرض الموقع بثاً مباشراً ما لم يتوفر مصدر HLS فعلي.

الملفات المنشورة: index.html، theme.css، website.js، player.html، live.json، news.json، news.js، editorial.html، privacy.html، manifest.webmanifest، sitemap.xml، sw.js، assets/ofuq-mark.svg.

## الأخبار

تعمل GitHub Actions في المستودع لتحديث news.json من RSS المصادر الرسمية كل 6 ساعات تقريباً. يتم عرض العناوين وروابطها فقط؛ النصوص والصور تبقى لدى ناشرها.

## بث مستقل عن يوتيوب

تعمل الشاشة بوضع عدم الاتصال. لتوصيل بث حقيقي عبر خادم HLS مصرح به، حدد mode=hls ورابط HTTPS صالحاً ينتهي مساره بـ .m3u8 داخل live.json. يحتاج البث الفعلي إلى خادم إرسال يوفر المقاطع وCORS والدعم التشغيلي المستمر؛ GitHub Pages لا ينتج بث فيديو حي بحد ذاته. لا تضع مفتاح RTMP أو كلمة مرور في مستودع عام.

## الربح

لا توجد إعلانات فعّالة أو اتفاقيات رعاية في النسخة الحالية، ولا توجد أرباح مضمونة. تفعيل دخل الإعلانات يعتمد على قبول الشبكة الإعلانية وتوافر نطاق وسياسات ومرور بشري حقيقي. لا تقم بإضافة إعلانات وهمية.
